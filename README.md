## How to install

Each snippet folder has its own README with specific notes. In general:

**WPCode**

1. Go to **Code Snippets > Add Snippet > Add Your Custom Code**.
2. Set the code type to **JavaScript Snippet** and paste the snippet.
3. Set insertion to **Auto Insert**, location **Site Wide Footer**.
4. Activate and save.

**Simple Custom CSS & JS**

1. Go to **Custom CSS & JS > Add Custom JS**.
2. Paste the snippet (without `<script>` tags).
3. Set **Where on page** to **Footer** and **Where in site** to **In Frontend**.
4. Publish.

Always test the full flow on your site after installing, including on mobile.
